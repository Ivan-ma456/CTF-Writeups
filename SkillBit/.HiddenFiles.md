# Challenge Information:
**Challenge Name:** .HiddenFiles

**Category:** Miscellaneous

# Challenge Description:
You've been given SSH access to a Linux system. The welcome message tells you there's a hidden flag somewhere in your home directory.

Can you find that hidden flag?


# Analysis:
The challenge provides a container to complete the challenge. Upon opening the machine, the message "You know there's a hidden flag somewhere in your home directory... Can you find it?" Using the command `ls -la` prints out all files in the current directory, including hidden ones, which shows a file named `.hidden_flag`. Using the command `cat .hidden_flag` prints the contents of the file, giving the flag.

**Commands used:**
- `ls -la`
- `cat .hidden_flag`

**flag:** `SkillBit{n0t_l3tt1ng_4_d0t_g3t_th3_b3tt3r_0f_m3}`

# Lesson Learned:
- Practiced using commands to view directory and file information
- Learned that files beginning with a . are hidden
- Learned that just because files are hidden doesn't mean they cannot be accessed
